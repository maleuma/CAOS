- 2-Monitor-Modus
- neue CAOS-UP HLDEZ und RDEZ
- dezimale Argumente bei WINDOW, COLOR und dem User-Bereich im Kommando CD

Download: [EPROM-Inhalte CAOS 4.8](https://www.kcclub.de/index.php/downloads/download/23-eprom-inhalte/223-caos48-patch7)

### CAOS 4.9
- Fullscreen-Editor fuer BASIC (ausgelagert in ASM-Ebene des USER-ROM)
- 16Bit-SWITCH fuer Module
- DEVICE-Umschaltung mit Name statt Nummer
- Erkennung Flash-ROM-Groesse bei M044
- Time-Kommando erkennt RTC auf Portadresse 55h (M064)
- Erweiterung Modulcheck auf mehrere Ebenen (z.B. M011 2* 64K RAM)

Download: [EPROM-Inhalte CAOS 4.9](https://www.kcclub.de/index.php/downloads/download/23-eprom-inhalte/311-caos-4-9)
